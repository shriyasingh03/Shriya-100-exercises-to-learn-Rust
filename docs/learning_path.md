# Rust Learning Plan

– Ch 1–3: Basics, variables, functions
Goal: Getting comfortable writing, compiling, and running Rust code.

– Ch 4–5: Ownership, borrowing, slices
Goal: Getting comfortable with ownership rules and string/vec handling.

– Ch 6–8: Structs, enums, pattern‑matching, Result/Option
Goal: Build a small CLI app using structs/enums and error handling.

– Ch 9–10: Error handling, generics, traits
Goal: Learn to validate, return Result, and use generics/traits.

– Ch 11–13: Testing, iterators, closures

– Ch 12–15: Smart pointers, Box, Rc, RefCell, basic concurrency
